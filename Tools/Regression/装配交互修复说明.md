# 装配卡片无法点击

原因：`InventoryItemSlotUI` 实现自定义 `IPointerClickHandler`，并不继承 `Selectable`。统一主题原先将所有没有 `Selectable` 的背景图设为 `raycastTarget = false`，编辑器迁移又将该值保存进了卡片预制体。卡片图标和文字本来就不接收鼠标命中，因此底盘、组件卡片虽然可见，却没有可点击的区域。

修复：

- 卡片预制体的背景恢复接收鼠标命中。
- 卡片初始化确保背景承担点击事件，兼容旧场景实例；图标和文字仍让点击穿透到卡片。
- 主题工具保留已有控件的命中设置，仅新添加的纯装饰背景默认不拦截。重新应用样式不会再破坏自定义点击或拖动控件。

没有改动物品品质、物流入库条件或装配配方。
