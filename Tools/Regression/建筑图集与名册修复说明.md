# 名册与统一建筑美术

## 名册

- 原界面收到每次人口事件都会销毁并重建所有居民行。当前 RTS_World_Master 场景把基地招募间隔覆盖为 1 秒，招募期间会频繁触发此行为；满员后总部会停止招募。本次没有修改招募节奏。
- 改为以居民 InstanceID 复用列表行，事件在 LateUpdate 合并。只有成员增减、筛选或排序变化才重排布局；普通数据变化原位更新，不重新绑定按钮监听。
- 名册不再参与全局主题的周期按钮覆盖，保留半透明背景、强调色和自身按钮状态。
- 资源汇总和人口容量数值不变时，不再广播变化事件；人口容量使用独立初始化标记，避免零容量反复初始化。

## 美术接入

图集：`Assets/Resources/Buildings/ColonyBuildings.png`。

3×2 布局，顺序为：基地、工厂、机甲装配站；住宅、仓库、空白。透明 PNG，Point 采样，无 mipmap，无纹理压缩。由 `BuildingAtlasImporter` 自动设置，不需要手动配置导入器。

建筑图集现已升级为正式 Sprite 子资源，已写入场景、预制体和图纸。地图主体、建造按钮、底部详情和放置预览使用相同图像。原有 SpriteRenderer 保留并隐藏，碰撞、占地、入口、建筑 ID 和功能不变。编辑模式直接显示新图，运行时保留已编辑的外观；详见《编辑器可见美术与UI.md》。

`BuildingBase.UseUnifiedBuildingArt` 可单独关闭统一图集，以保留某个建筑的专用美术。入口小标记表示实际交互格，不根据绘制的门口重定位寻路入口。

顺带修复取消未放置建筑预览时误触发物流遗留处理的风险：只有正式注册的建筑销毁时才释放其存储容器。

## 生成记录

使用内置 image_gen 工具及 imagegen 技能。第一张为设计草案，第二次定向编辑处理透明背景；项目仅使用第二张。没有使用 CLI 或外部 API 密钥。

生成提示词：

```text
Create ONE production-ready transparent PNG sprite atlas for a Unity top-down pixel art colony management / mech defense game. Asset is a coherent FIVE-building industrial colony set. Canvas 1536x1024 with EXACT equal 3 columns x 2 rows (each cell 512x512). Top row left: command headquarters, middle: components factory, right: mech assembly hangar. Bottom row left: residential habitat, middle: resource warehouse, right: completely EMPTY transparent. Each building centered and fully contained inside its cell with generous transparent margin, maximum silhouette 400x400. All sprites strictly orthographic overhead bird's eye ROOF view, aligned square grid, NOT isometric, NOT 45 degree perspective. Identical pixel scale: emulate carefully hand-drawn 64x64 pixel sprites enlarged with nearest neighbor, crisp square pixels, no blurry antialias. Shared blue-grey steel palette, very dark navy outlines, muted teal trims, occasional small warm amber lights. HQ square armored roof with central communications dish and antenna. Factory square ribbed roof, industrial vents and furnace orange accent. Assembly hangar square roof mostly open showing a simple mech frame on maintenance platform, yellow edge marking. Habitat compact square modular roof with skylight and small utility unit, soft warm window accents. Warehouse compact square corrugated steel depot with crate/load-bay motifs and teal trim. Strong small-scale legibility, attractive moderately detailed sprites. Consistent top-left lighting but no long cast shadow, no ground terrain tiles, no external decorative props, no text, labels, numerals, logos, grid lines or watermarks. True transparent background and transparent space between the buildings. This is a single atlas, not a presentation sheet.
```

透明背景编辑提示词：

```text
Edit this exact 3x2 building sprite atlas. Remove ALL of the dark gradient background, glows and cast shadows so every pixel outside each building silhouette is genuinely alpha-transparent. Keep all five building designs, colors, small details, exact positions, identical scale, cell layout, canvas dimensions, and crisp pixel edges unchanged. Bottom-right cell entirely transparent. Do not add checkerboard pixels or a flat replacement background. This is a game sprite atlas, transparency is mandatory.
```

## 测试

沿用隔离 Unity 项目运行方式。将 `RosterAndBuildingVisualChecks.cs` 放入副本 Assets/Editor，执行 `RosterAndBuildingVisualChecks.Run`。检查列表实例稳定性、滚动位置、增删、筛选、主题覆盖、无变化事件抑制，及图集透明度、地图主体/图标一致性、占地入口和存档 ID 保持、放置预览染色。

生成的对照截图和结果位于副本 RosterVisualResults，最终副本保存到 `Tools/Regression/Artifacts/RosterVisuals`。

2026-09-27 验证：名册与建筑显示 41 项通过；物流回归 39 项通过，包含完整场景重载、资源位置与总量、组件身份和居民搬运配置的存取。测试使用独立项目副本，没有读取或覆盖主项目玩家存档。结果分别见 `results.txt` 和 `logistics-regression.txt`。
