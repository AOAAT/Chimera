# 居民工作闭环

## 当前规则

工厂使用科技熟练度计算员工贡献。居民贡献由同一个 `ResidentWorkCalculator` 提供给模拟和 UI：

```text
个人生产力 = (科技熟练度 × 纪律修正 + 特性固定加成) × 特性倍率
纪律修正范围 = 0.9 ～ 1.1
工厂速度倍率 = 1 + 总生产力 × 0.15
生产线数量 = 1 + floor(总生产力 / 2)，最多 3 条
```

无员工时，工厂仍有一条基础生产线和 `1.0x` 速度。暂停的任务不占生产线，队列中最靠前的未暂停任务依次进入可用生产线。

`FactoryBuilding` 暴露以下可调参数：

- `SpeedBonusPerProductivity`
- `ProductivityPerAdditionalLine`
- `MaxProductionLines`
- `WorkDomain`

## 当前居民差异

新居民会随机生成科技、血肉、魔能熟练度，以及纪律、社交和勇气三项性格倾向。当前只有纪律参与工作计算，社交与勇气分别为关系和机甲驾驶预留。

首批数据驱动特性为：

- 勤勉：生产力倍率 `1.15`
- 专注：固定增加 `0.2` 生产力
- 散漫：生产力倍率 `0.85`

特性通过稳定 `TraitID` 写入居民存档。显示名、描述和数值可以调整，但已发布的 `TraitID` 不应修改或复用。

## UI 同步

建筑岗位变化统一触发 `BuildingBase.OnStaffChanged`。建筑面板监听该事件并刷新岗位容量、员工卡片、个人贡献和工厂产能摘要。员工卡片、工厂速度和生产线解算均调用同一贡献计算器。
