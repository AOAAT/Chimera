# 世界美术规格：50 PPU

本次接入范围为地图基础地块、居民、统一建筑和拼装机甲。世界基准为 50 个素材像素 / 世界单位，当前地图一格为一个世界单位。采用 SpriteRenderer 直接旋转、Point 采样，未启用低分辨率整屏渲染。

## 已接入的资源

- 居民：`Assets/Art/Residents/Worker48.png`，192×96 图集，八张 48×48 精灵，50 PPU，轮廓最高 44 像素。由保留的放大源稿重新采样，没有拉伸旧的 32×32 图集；旧图集保留供回溯。当前仍是一种基础外观，没有逐帧步行动画。
- 地块：`Assets/Art/World50/Grid50.png`，50×50、50 PPU，已写入编辑器地图预览。
- 建筑：`Assets/Resources/Buildings/Pixel50/` 五张原生尺寸 PNG。建筑原始高分辨率图集保留；现有占地、交互格和物流连接不变，当前建筑显示缩放为 1。未应用比例小样里的 3×3 或 4×4 占地提案。
- 机甲：玩家与模块化敌人的机甲预制体整体缩放为 1。33 张手绘底盘与组件原图、原导入参数均保留。
- 少数旧组件：额外缩放被整理到 `Assets/Art/World50/Components/` 的原生尺寸副本，组件数据指向副本，缩放归一为 1。连接与发射偏移同步换算。像素取整导致的尺寸偏差不超过 0.01 世界单位。

不是所有资源文件都必须改成 50 PPU：UI 与源稿各自保留合适的规格。本轮未处理独立怪物贴图、弹药和旧特效的显示规格。

## 装配与战斗表现

`WorldPixelMetrics` 统一世界密度和组件绘制顺序。底盘在后，各组件按插槽索引稳定排序，装配编辑器与详情预览使用相同插槽顺序。这是固定遮挡规则，不会自动判断武器转到躯干背后时切换前后层。

装配预览显式使用 `精灵像素尺寸 / PPU × UI世界单位换算`，不再依赖 Canvas 的 Reference PPU。完整装配会适配预览区域，保留点击节点、选择组件、外形更新的流程。UI 可以放大机甲，不改变世界中的密度。

狙击枪枪口按原图 96×48 的右侧枪管口校准。`MuzzleOffset` 属于组件转轴的局部坐标，不再乘战斗射程系数。枪口跟随转轴旋转，子弹生成逻辑继续使用同一个 MuzzlePoint。近战链锯的零偏移未擅自改为远程枪口。

机甲显示从原 0.7 倍变为 1 倍，宽高约增大 43%。底盘命中盒按贴图生成；部署机甲保留半径 0.35 的移动碰撞圆，枪管与展开武器不作为整块寻路占地。测试检查了实际路径移动、碰撞尺寸与六个角度的枪口位置。

## 编辑器与存档

- 已保存到预制体、资源引用及主场景，编辑模式可见。
- `WorldPixel50Ready.txt` 导入后会在已打开场景中更新相关美术引用和地块预览。保留已有未保存修改；原本不脏的场景才自动保存。不会切换 Play 或重新打开用户的场景。
- 没有更改居民、机甲或组件的永久 ID，没有新增存档字段。旧存档通过原有资源引用恢复新显示规格。
- 主地图仍为 64×64、CellSize=1、原点 (-31.5,-31.5)。如果之后改动 CellSize 或建筑占地，应按新的世界尺寸检查并重做相应原生素材；不能靠任意缩放贴图维持统一密度。

## 美术维护

菜单：`Tools → Chimera → 美术规格 → 整理50PPU游戏资源`。居民菜单为 `Tools → Chimera → 居民美术 → 从源稿生成48像素精灵（50PPU）`。

工具会重新生成游戏用纹理和相应预制体；如果已人工修整派生纹理，请先保留版本，再决定是否重新生成。保留的 AI 源稿提示词位于 `ArtSource/Residents/Worker32_v1/README.md`。

新组件原则上在 50 PPU、1 倍缩放下制作，通过像素尺寸设计体型。挂点可以是小数坐标，不为了像素对齐而强制改变既有机械连接。任意角度旋转仍会产生重采样的边缘变化，这是已确认的直接旋转路线。
