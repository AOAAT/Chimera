# 编辑器矩形地图设置

打开 `Assets/Scenes/RTS_World_Master.unity`，通过菜单 **Tools → Chimera → 地图 → 地图设置** 选中地图对象，在 Inspector 中修改参数。

1. 设置“地图宽度（格）”和“地图高度（格）”，两者独立，范围均为 1～512。
2. 通常保持“每格世界尺寸”为 1。地图原点指的是**左下角格子中心**，不是地图中心。
3. 点击“更新地图预览”，Scene 中立即显示新地面；无需进入 Play 模式。
4. 可点击“在 Scene 窗口聚焦地图”查看全图，再按 Ctrl+S 保存场景。

“将地图中心设为世界原点”只修改地图原点，之后需要更新预览；现有建筑不会随之移动。“默认地面”选择地面颜色类型；更换 `RTSMapVisuals` 地块图片或颜色后，点击“更新地块图像与颜色”。平铺图片会使用 Full Rect 网格导入设置。

地图更新支持 Undo/Redo，只重建 `Visual_Grid_Tiles`，不会删除建筑、居民或其他手工放置的对象。缩小后超出地图的建筑会在 Inspector 中提示，需要手动移动或重新扩大地图。地图尺寸在编辑模式下配置，运行中不可通过该面板调整。

当前场景为 64×64 格，原点为 (-31.5, -31.5)。预览按最多 32×32 格一个区块绘制并序列化到场景，运行时复用；逻辑网格、建造边界、寻路与摄像机移动边界使用同一份尺寸设置。“聚焦地图”只调整 Scene 视图，不修改游戏摄像机的缩放。

当前尺寸属于**场景配置**，尚未加入存档中的独立地图规格。调整地图后建议使用新游戏验证，旧存档中的建筑和居民位置不会自动适配新边界。512 的上限是编辑器输入限制，不代表已经完成大规模居民与寻路的性能优化。

## 验证

`Tools/Regression/MapEditorChecks.cs` 可复制到隔离项目的 `Assets/Editor` 下，通过 `MapEditorChecks.Run` 执行。覆盖矩形尺寸、不同格子大小和原点、最大尺寸分块、坐标转换、建筑保留与越界提示、撤销重做、预览持久化，以及运行时地图复用、寻路和摄像机移动边界。测试输出保存在隔离项目 `MapResults` 下。
