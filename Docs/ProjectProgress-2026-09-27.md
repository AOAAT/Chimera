# Chimera 阶段性进度总结

日期：2026-09-27。依据当前代码、专项交付文档和已有回归记录。本次仅整理进度，没有修改游戏逻辑，也没有重新启动 Unity 或复跑测试。

## 阶段判断

项目已具备可运行、可保存的殖民地生产与模块化机甲原型。居民工作、自动物流、品质组件、单仓库库存和机甲装配已经接通；资源获取与正式敌袭尚未接通，因此还不是完整的殖民地塔防游戏循环。不宜用单一完成百分比衡量尚在扩展的设计范围。

当前已接通的流程：

居民招募与派驻 → 员工影响生产效率与并行产线；开启搬运的居民 → 仓库取料 → 工厂收料生产 → 成品搬运入库 → 选择底盘与组件装配 → 世界机甲移动与战斗。

边界：正式采集入口尚缺；建造和装配尚不产生物理送料任务；机甲部署尚不要求驾驶员；战斗底层存在，但没有正式敌袭、守卫目标和胜负闭环。

## 已实现的基础

| 生产 | 排队、暂停、取消、多条生产线；员工提高速度与产线数；物流收料、开工扣料和出货区 | 最终生产时长与配方平衡；采集、农业和多级精炼链 |
| 自动物流 | 搬运权限、背包货物、取送任务、仓库容量与预留、工厂补料与出货、异常退货/遗留货物、读档恢复 | 通用工作优先级、建造送料、装配送料、主动仓间调拨、个人口粮与资产 |

| 仓库 | 地图仓库、单仓库实际库存、容量、收纳设置；滚动列表、筛选、搜索、详情、底盘/组件独立改名 | 专业仓库分工规则与完整仓储策略 |

| 世界美术 | 地块、统一建筑、居民与模块化机甲接入 50 PPU；居民 48×48 帧；组件原图保留，旧缩放生成适配副本；挂点、枪口及预览比例校准 | 独立怪物、弹丸和旧特效尚未统一；居民随机外貌、独立立绘及行走动画未完成 |

目前默认工厂无员工仍有一条基础产线；生产力每增加 2 开放额外产线，默认最多 3 条。这些属于现行可调原型规则，并非最终平衡结论。

居民背包已承担运输容器职责，不等于个人物品所有权或交易经济已经实现。等级/经验与驾驶状态字段的存在，也不等于对应成长或驾驶玩法已经接通。

这些验证覆盖具体功能和回归场景，不代表完成了长期游玩、大规模居民压力、所有分辨率或独立发布版本验收。本次总结没有重新运行测试。

## 后续建议顺序（尚未开始实施）

1. **资源采集最小闭环。** 先用一种现有资源（例如废料）实现野外资源点、指定采集、居民自动执行、产物交给现有物流入库。验证资源点耗尽、任务取消/中断、仓满、不可达和存读档，暂不一次决定全部资源树。
2. **基本工作管理。** 将采集和搬运纳入统一开关与优先级，沿用已有执行逻辑；为日后烹饪、医疗、维护留扩展入口。与第一步只共建必要任务基础，避免提前重写所有 AI。
3. **最小敌袭闭环。** 确定防御目标、一类敌人、来袭提示、简单进攻路线、胜败与战后反馈，让生产机甲有明确用途。
4. **居民驾驶机甲。** 先验证单人驾驶、上下机、生产与驾驶的人力取舍，再扩展多人班组、特性影响与成长。
5. **生活与长期经营。** 在基本游戏循环稳定后分批接入饮食、精力、农业、精炼、社交关系和个人资产；每次只闭合一条新的需求链。

下一里程碑建议：玩家不依赖调试补给，可以指派采集、运回材料、生产并装配机甲；随后用最小敌袭检验这条经营链的价值。
