# 生产状态与装配预览

本次保留米白与铜色主题、单仓库库存界面，以及“点击节点 → 选择组件 → 外形实时变化”的装配操作。

## 物品卡片

组件卡片显示名称、Mk 型号和品质名称；随机品质百分比、实际属性、词条留在详情或悬停卡中。装配卡片固定文字大小，长名称省略显示，悬停可查看全名。品质文字与主题正文色混合，提高浅底板上的可读性。

## 生产队列

任务行独立显示名称、状态、原因/处理建议、进度条，以及暂停/继续和取消按钮。拖动左侧图标可调整顺序。

- 等待原料：列出当前缺少的可用资源；已预留给当前任务的货物不重复算作短缺。
- 等待搬运：区分尚无搬运者与居民正在取货。
- 运输途中：居民已取货；部分资源仍短缺时同时说明。
- 排队中：等待生产线或前方任务；原料齐备时显示“原料已齐”。
- 生产中：显示生产线、按实际速度折算的剩余时间。
- 已暂停：提示如何继续，并保留已送达原料。
- 出货区已满：成品和生产中预留的位置一起计算，提示搬走成品、检查仓库容量。
- 原料区容量不足/被占用：区分配方本身过大与其他任务占用空间。

`ProductionStatusView` 只读现有订单、仓库和搬运任务，不调用备料或消耗接口，不依赖可能过期的 `LogisticsStatus` 字符串。任务行每 0.25 秒刷新；持续悬停的状态卡每 0.5 秒更新，游戏暂停时仍可刷新界面。

## 装配预览

节点增加编号与状态标记：浅色为空闲、绿色为已安装、铜色为当前选中。预览区上方显示当前节点名称和状态；标记不拦截点击，也不改变组件原画。

选中节点后，悬停适配组件或“卸下当前组件”，共享悬停卡顶部展示整机属性的前后变化。计算采用与正式装配相同的运行时属性解析，包含当前组件实例的品质、词条和装配效果；替换时先移除旧组件的贡献。预览不改写库存、物流预留或机甲档案。

当前比较生命、护甲、格挡、质量、动力、移速六项，只列发生变化的项目。这不是伤害或战力预测；武器局部属性、技能和条件效果仍查看下方组件说明。数字以未进入战斗的装配基础状态为准。

## 编辑器与验证

新任务行、卡片布局和装配提示文字已保存到预制体与场景，不依赖进入 Play 才生成静态布局。运行时节点标记随所选底盘动态创建。

`Chimera_UI_Skin_v2` 与版本就绪标记负责已打开场景的原地升级；已有未保存的编辑不会被强制保存或重新打开。

隔离测试脚本：`UIClarityChecks.cs`、`ItemHoverChecks.cs`、`AssemblyInteractionChecks.cs`，均位于 `Tools/Regression`。检查生产状态、只读预览、实际点击安装、取消回库、悬停更新与小尺寸显示；截图和结果保存于 `Tools/Regression/Artifacts/UIClarity`。
