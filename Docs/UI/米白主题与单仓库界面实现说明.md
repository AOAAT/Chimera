# 米白主题与单仓库界面

2026-09-27

本次采用 B 的米白、暖铜配色与 A 的简洁边框。仓库、殖民地名册、建筑/居民/机甲详情、装配、物品详情及菜单使用同一套主题；物流管理保留原有外观，方便后续独立改成工作管理界面。

## 仓库

- 入口展示某一座仓库的实际库存，顶部可切换仓库，容量显示为该仓库已用/最大容量。选中仓库建筑打开时，直接定位该仓库。
- 左侧固定四列，约三行可见，滚动浏览，无翻页按钮。列表按可见区域复用显示，避免大库存一次创建大量 UI。
- 类别、组件类型、标签与名称共同筛选。资源继续按数量显示，底盘和组件逐件显示。
- 右侧为固定详情区，内容单独滚动。滚动条覆盖在预留位置，闲置淡出，不推动卡片重新排版。
- 底盘、组件可以独立改名，最长 24 个字符，留空恢复原名；名称检索同时支持自定义名称与原始型号。改名会随存档保存，不改变同型号其他物品。

## 装配与其他界面

装配窗口分为属性、实物预览、适配组件三栏。仍然使用实际底盘的节点坐标与组件图像：点击节点选择组件后，外形与属性实时更新。没有改成固定装备槽。

建筑、居民与机甲底部详情使用相同外框尺寸，名称和图像位于左侧，内容居中，操作列固定在右侧。生命数值放在血条上方，正文采用深色文字。

主题已写入场景和预制体，不依赖进入播放模式才替换。新编辑器脚本 `ChimeraIvoryAuthoring` 处理当前仍打开的旧场景；已有未保存修改时只标记场景为脏，不自动覆盖这些修改。也可通过 `Tools > Chimera > 美术与UI > 应用米白主题到当前场景` 应用主题。

清理了 28 张已无引用的旧背景/边框贴图及其 meta，包括仓库、装配和各级物品详情旧背景。实际建筑、底盘、组件图像保留；物流仍使用的圆角纹理保留。旧背景素材的序列化引用与运行时恢复入口均已清理。

## 数据兼容

为支持底盘逐件命名，底盘改用稳定实例 ID，物理货物键为 `chassis-instance:<ID>`。旧版本按型号堆叠的底盘在载入时原地拆分，保留所在仓库/生产输出位置；旧搬运任务重新规划。取消装配和回收返回同一底盘实例。

存档版本升至 5，旧版本向前迁移。新版存档不建议交给旧版程序读取。回归测试使用隔离工程，没有改写主工程的玩家存档。

## 验证与截图

在 `.utmp/AssemblyRegression` 隔离副本中使用 Unity 2022.3.62f3c1 编译、烘焙场景和执行播放模式检查，主编辑器不进入播放模式。

- `Tools/Regression/IvoryThemeChecks.cs`：真实事件射线点击、单仓库存货、独立改名、双名称检索、滚动列表、下拉遮罩、JSON 名称恢复、旧底盘迁移、物流配色保持。
- `Tools/Regression/AssemblyInteractionChecks.cs`：点击装配入口、选择底盘、点击核心/移动节点、安装实际组件、预览贴图变化、确认生成机甲、取消后库存恢复。
- `Tools/Regression/LogisticsRegressionChecks.cs`：搬运、生产原料/输出、在途恢复、完整场景存档重载及物品位置/身份保持。

测试源码位于 Tools 下，不加入正式玩家程序集；复跑时将三份检查脚本复制到隔离工程的 `Assets/Editor`，通过 Unity `-batchmode -executeMethod <类名>.Run` 启动。场景烘焙入口为 `ChimeraIvoryAuthoring.BakeProject`。

最终检查记录和运行时截图位于 `Tools/Regression/Artifacts/IvoryTheme`。截图使用专门的 UI 渲染相机隔离游戏世界；截图中的大量同款底盘是滚动/实例验证用的测试库存，不是新增初始物资。
