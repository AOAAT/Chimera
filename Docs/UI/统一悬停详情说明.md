# 生产与装配的统一悬停详情

2026-09-27

生产列表与装配列表共用 `ItemHoverTooltip`。旧生产悬停不再调用 `SetFixedAnchor`，也不再通过临时创建随机组件来显示配方。米白底、深色文字与完整边框均由独立预制体提供，不再依赖旧详情背景贴图。

## 交互规则

- 停留 0.25 秒出现，使用非缩放时间，游戏暂停也可查看。
- 以物品卡片或节点的矩形定位，顺序考虑右、左、上、下；自动限制在屏幕安全区域内。同一目标显示期间不跟随鼠标微动。
- 优先避开当前目标、整机属性和操作按钮，再尽量避开装配预览；生产页将底部生产栏列入避让范围。空间不足时比较统一的角落备用位置。
- 浮窗不接收鼠标事件。点击仍直接执行生产或安装，离开目标、滚动、关闭窗口、销毁目标、改变分辨率时收起。
- 没有预留独立详情栏的浮窗布局无法保证完全不覆盖其他内容；长说明或紧凑窗口中优先保证当前目标与关键按钮可见。

## 信息来源

- 生产配方：型号基础属性、原料成本、基础耗时、当前效率下预计耗时；明确说明等待原料/排队不计入耗时，成品随机品质与词条尚未确定。
- 实际物品：自定义名称、原始型号、品质、计算后的实际属性、词条及描述。
- 空节点：部位名称与允许安装的组件类型。
- 已安装节点及组件外形：当前实际组件的信息；点击节点、选择组件和实时换装逻辑保持不变。

仓库仍使用其右侧固定详情区。

旧 `ItemDetailPanelUI` 预制体、脚本、场景实例及其空画布现已移除；生产页的旧详情定位锚点也已删除。机甲详情窗口的底盘和已安装组件改用相同的悬停卡，改装和关闭窗口时同步收起，避免重新调用旧页。

## 编辑与验证

预制体：`Assets/Resources/UI/ItemHoverTooltip.prefab`。可以直接打开预制体检查外框、字体与布局；预制体模式显示示意内容，运行时初始隐藏。重建入口：`Tools > Chimera > 美术与UI > 生成统一悬停详情预制体`。

`Tools/Regression/ItemHoverChecks.cs` 在隔离 Unity 工程检查多种屏幕尺寸的边界定位、暂停下的出现延迟、射线点击、配方与实例数据、旧信息隐藏、滚动/关闭清理、空节点/已安装节点及实际安装。`AssemblyInteractionChecks` 继续验证完整装配、生成机甲和取消归还库存。

最终记录与截图：`Tools/Regression/Artifacts/ItemHover`。截图使用独立 UI 渲染相机，排除场景图像；其中“测试独立核心”和“装甲测试”是回归测试数据，不写入玩家存档。
