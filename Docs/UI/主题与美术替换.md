# UI 主题与美术替换

当前主题保留米白底板、铜色主按钮和简洁边框。物流管理的主题与布局暂不参与本次改造。

## 使用方式

打开 **Tools → Chimera → UI主题 → 打开主题配置**，对应资源为 `Assets/Resources/UI/ChimeraTheme.asset`。

- 调整 Window、Header、Surface 等颜色可以更改窗口、标题栏和卡片配色。
- Font 留空时保留各界面原字体；设置时请使用包含中文字符或配置了中文回退的 TMP 字体资源。
- Window Art、Card Art、Button Art 等可以指定新背景与按钮素材。
- 彩色原画通常关闭 Tint Artwork；单色素材可以开启，让图片乘以主题色。
- 面板图在 Sprite Editor 中设置 Border 后自动使用九宫格切片，边角不会随着窗口拉长。
- 按钮支持 Normal、Hover、Pressed、Selected、Disabled。使用图片反馈时建议配齐五种状态；缺失状态回退到普通图。无状态图时使用主题的颜色反馈。

修改后点击 **预览 / 应用到打开的场景（可撤销）**，再按 Ctrl+S 保存场景。点击 **同步到 UI 预制体** 将主题保存到物品卡片、仓库、名册、悬停卡等预制体中。该操作不进入运行模式，也不重新排列控件或清空物品数据。

首次交付带有保存好的主题与布局。已经打开且有未保存修改的场景会在编辑模式中原地接入主题，不强制重新打开或自动保存，原有地图和建筑编辑会保留；请自行 Ctrl+S 保存。

## 如何准备 AI 美术素材

推荐按用途分别提供 PNG：窗口底板、标题栏、卡片、普通按钮、主操作按钮、危险操作按钮。图标和物品原画仍在各自的数据或预制体中配置，不由窗口主题覆盖。

生成时保持同一色板、边角语言、光照和像素密度，预留足够的文字区域。按钮各状态保持同样尺寸和边距。图片中的标题、物品名、数值应留空，使用 Unity 文字显示，便于中文、改名和动态数值更新。

导入时设为 Sprite (2D and UI)；像素风素材通常使用 Point 过滤、关闭压缩，并检查缩放后的实际效果。生成图片仍需人工或工具检查透明边缘和九宫格切片，不应把一整张界面示意图直接铺在可交互界面下面。

## 开发约定

- `ChimeraUIThemeConfig` 存储颜色、可选字体和美术资源。
- `UIThemeBinding` 记录明确的显示用途，应用样式时不改变 RectTransform、点击拦截或文字内容。没有逐帧主题扫描。
- 新建动态底板使用 `UIThemeBinding.Bind` 指定 Window、Surface、Button 等用途；动态文字同样绑定角色。
- 品质颜色等由业务控制的文字使用 None 角色，只同步字体。物品图标、机甲预览和血条填充方式不得当作普通底板处理。
- 留空主题图片时回到原有底板；手工替换的新 Sprite 会成为新的回退素材。旧按钮状态图会在切回纯色模式时清理，避免残影。
- 普通主题应用与历史 UI 清理分离。维护菜单中的“清理当前场景的已知旧版UI引用”只负责历史素材引用，不会随着换肤自动执行；主题应用也不删除美术文件。
- 初次布局整理与后续换肤是不同操作。后续换肤保留手工调整的布局。

## 本次交互完善

仓库复用最多 24 张可见卡片，筛选和库存变化不再销毁重建所有卡片。保留四列滚动、单仓库库存、改名、搜索与详情。生产配方增加名称，生产队列分开图标、名称、状态、进度和暂停/取消按钮。装配适配组件网格随可用宽度调整，节点安装和实时外形变化逻辑保持原有行为。

验证脚本位于 `Tools/Regression/UISkinChecks.cs`，配合 `IvoryThemeChecks.cs`、`ItemHoverChecks.cs`、`AssemblyInteractionChecks.cs` 在隔离项目运行；生产项目不需要把这些测试脚本放入 Assets。
